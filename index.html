📚 Plano de Ensino

Gerador de Tabela do Plano de Ensino

Monte sua tabela de plano de ensino com base no número de semanas, data de início e dias de aula. Os feriados nacionais são preenchidos automaticamente.

    v. 2.2.0 - Desenvolvido por Thiago G. Traue - Projeto no GitHub

    Restrições de período

    Cadastre períodos como semana de provas ou de palestras. As datas de aula dentro do período recebem a descrição automaticamente na tabela.
